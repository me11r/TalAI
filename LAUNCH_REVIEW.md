**Публичный запуск пока заблокирован. Ничего не опубликовано.** Документы и технические изменения подготовлены для проверки владельцем. Это не заключение о соответствии законодательству, GDPR или WCAG.

## Фактический аудит и изменения

До изменений существовали SQLite и файловый каталог, но GET/PUT проекта, архивирование, загрузка и чтение оригиналов не требовали входа. Клиентский переключатель ролей не был авторизацией. Тип файла определялся только расширением. SDK карты загружался сразу. Эти пути теперь защищены серверной сессией одного оператора; без настроенного кода доступ закрыт. Произвольная регистрация и изоляция нескольких организаций не реализованы, поэтому публичный приём приватных материалов не открыт. Пользовательские записи, исходные координаты, модели, история и прежние ключи сохранены.

Обнаруженные данные:

| Данные | Место и доступ | Назначение |
|---|---|---|
| Деревья, координаты, источники, даты, измерения | SQLite; рабочая копия localStorage; один авторизованный оператор | Реестр и сопоставление |
| Заметки, исполнитель, описание задач, история с деморолью | SQLite и браузерная копия; возможны имена/контакты в свободном тексте | Организация обследований |
| RGB, тепловые файлы, орто, GLB/glTF, JSON результатов | Серверный каталог uploads, защищённый маршрут; оператор и администратор сервера | Материалы обследования |
| Оригинальное имя, MIME, размер, дата загрузки, ссылки, привязка | SQLite; метаданные проекта | Связь материалов с обследованием |
| EXIF/GPS, камера, лица/номера в кадре | Сохраняются внутри оригинала, автоматически не извлекаются и не обезличиваются | Сохранение рабочего оригинала |
| Превью RGB | Отдельный WebP на сервере | Галерея, оригинал не заменяется |
| Согласия и условия | SQLite: purpose/version/time/choice, связь с сессией, файлом и проектом, отзыв | Доказательство совершённых действий; юридическая достаточность требует проверки |
| Сессионный токен | HttpOnly cookie, хеш на сервере, 8 часов; истёкшие сессии очищаются при обращении | Доступ к единственной рабочей области |

Код не содержит регистрации, контактной формы отправки сообщений, оплаты, аналитики, маркетинговых рассылок или внешних шрифтов интерфейса. Ресурсы подписей карты относятся к SDK 2ГИС. Сетевых access logs приложение не ведёт; IP временно используется в памяти для ограничения попыток входа. Настройки логов будущего прокси/хостинга не предоставлены. Доступ администратора к файловой системе не заменяется прикладной авторизацией. Шифрование диска, страна сервера, резервные копии и их сроки не подтверждены.

Текущие хранилища браузера: `talai.project.v3`, `talai.privacy.v1`; старые `greenwatch.project.v1` и `greenwatch.project.astana.v2` сохраняются для миграции. В старых версиях могли оставаться фото data URL. Новые большие файлы сохраняются на сервере. При входе пользователь явно предупреждён о переносе прежних локальных данных. На выходе удаляется текущая браузерная копия, отдельная подтверждаемая команда удаляет прежние локальные копии. Это не удаление серверных материалов.

Подтверждается удаление будущей посадки. Она не выдана за действующий консолидированный текст.

[Официальное разъяснение от 26.03.2026](https://www.gov.kz/org/aktobe-alga/press/article/details/229933) подтверждает необходимость определить владельца, состав/период согласия, передачу третьим лицам и хранение базы в Казахстане. Для запуска юристу нужно сверить актуальные статьи и подзаконные правила, основания обработки данных людей в кадре, требования к форме согласия, трансграничной передаче, срокам ответов/уничтожения, инцидентам и перечню мер защиты. Отметки в MVP не объявляются достаточным юридическим согласием для публичного сервиса с неизвестным оператором.

GDPR не объявлен автоматически обязательным для казахстанского проекта. Нужно установить наличие подразделения в ЕЭЗ, целевого предложения услуг людям в ЕС или мониторинга поведения в ЕС; одного доступа к сайту недостаточно. Основание оценки — [EDPB, Guidelines 3/2018](https://www.edpb.europa.eu/our-work-tools/our-documents/guidelines/guidelines-32018-territorial-scope-gdpr-article-3-version_en). ## Проверки

- TypeScript + production build проходят; 10 доменных тестов проходят.
- 4 Playwright-регрессии: доступность данных без карты, серверная валидация, однократная миграция старых записей и оригинальных фотографий без удаления прежнего ключа; перемещение посадки с клавиатуры без карты и сохранение после перезагрузки.
- `storage-check`: SQLite и оригинальные байты после перезапуска, запрет завершённого будущего обследования, корректный GLB.
- `launch-check`: анонимные документы; отказ/сохранение выбора/отзыв карты; серверный отказ без согласия; защита файлов и от подмены расширения/пути; CSRF; выход; сохранение после перезапуска; отдельный PNG-экспорт действительно убирает EXIF и сохраняет размеры. Проверены клавиши Tab, Shift+Tab, Enter, Escape и возврат фокуса; создание посадки доступно через координатные поля без карты.
- axe на девяти экранах: 0 найденных нарушений выбранных правил WCAG A/AA. Не проверяет всё соответствие, все данные и все варианты canvas-карты.
- Машинный отчёт: `screenshots/launch-check.json`. Скриншоты: `talai-privacy-review.png`, `talai-launch-map.png`, `talai-launch-history.png`, `talai-privacy-settings.png`.

Сервер ограничивает каталог хранения правами 0700, БД и новые файлы — 0600; размещение каталога внутри public/dist запрещено. `security-check.mjs` проверяет закрытую конфигурацию, отдельные записи выбора, отзыв, смену кода, CSRF и отклонение внешних URI моделей. Это не заменяет аудит инфраструктуры и резервных копий.

В headless Chrome с программным WebGL редактирование параметров при immersive-ракурсе 3D давало таймауты. Сценарий разделён: выбор/перемещение и слои проверяются в 3D, параметры — в 2D с активными собственными GLB. Обновление моделей теперь затрагивает только изменённые объекты. Производительность на реальных устройствах и полный ручной проход всех 3D-взаимодействий требуют отдельной проверки.

Финальный `browser-check --fast` прошёл: реальный SDK, выбор GLB кликом, отключение собственного слоя, неизменность координат при вращении, перемещение/параметры/перезагрузка/удаление, оригинал и превью, изоляция дат и сравнение, без ошибок JavaScript. Подробности: `screenshots/browser-results.json`. Индикатор сохранения перенесён в фиксированную область шапки, чтобы ввод не менял размеры карты; подтверждение показывается после успешного серверного ответа.

После последней правки индикатора сохранения повторно прошли все 4 Playwright-теста и аудит девяти экранов без загрузки карты: `screenshots/launch-check-no-map.json` (0 найденных нарушений axe, нет ошибок JavaScript). Полный сетевой прогон с картой сохранён отдельно в `screenshots/launch-check.json`; реальный 3D-сценарий — в `screenshots/browser-results.json`. Последняя production-сборка проходит. Ни один тест не использовал рабочее хранилище пользователя.
