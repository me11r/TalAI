# Демонстрация TalAI на Vercel

**Публичное демо: https://talai-one.vercel.app**

Первый деплой выполнен через официальный CLI в проект `bulan4/talai`. Прямое подключение GitHub пока не удалось: для автоматических деплоев нужно подключить `me11r/TalAI` в Vercel → Settings → Git.

## Что будет опубликовано

Статическая демонстрационная версия: интерфейс, карта 2ГИС, собственные GLB, реестр, планирование и история. Изменения каждого посетителя хранятся отдельно в его браузере. Пароль оператора не нужен. Файлы в этой версии не принимаются, старые локальные записи не импортируются, рабочая SQLite не публикуется.

`.vercelignore` исключает локальные credentials и рабочее хранилище из отправки через CLI.

`vercel.json` задаёт сборку `npm run build:demo`, каталог `dist` и маршруты документов. Нельзя заменить эту сборку обычной `npm run build`: она предназначена для закрытого серверного режима.

Обычный сервер с локальной SQLite нельзя перенести на Vercel как постоянное хранилище: [официальное объяснение Vercel](https://vercel.com/kb/guide/is-sqlite-supported-in-vercel). Для полной облачной версии понадобятся отдельно спроектированные база, приватное файловое хранилище и контроль доступа. Текущая серверная версия сохраняется для локальной работы.

## Первый деплой через GitHub

1. Отправьте проверенные изменения в `https://github.com/me11r/TalAI`. Не добавляйте `.env.local`, `storage/`, пароли и пользовательские материалы.
2. В Vercel: **Add New → Project → Import Git Repository → me11r/TalAI**.
3. Выберите **Vite**, корневой каталог репозитория, Node.js **22.x**. Параметры сборки берутся из `vercel.json`.
4. В Environment Variables добавьте **VITE_2GIS_API_KEY** для Production и Preview. Это браузерный ключ карты, не пароль TalAI. `TALAI_OPERATOR_PASSWORD` для демо не нужен.
5. Выполните Deploy. Скопируйте выданный Vercel URL; не угадывайте его по имени репозитория.
6. В кабинете 2ГИС разрешите этот origin/referer и нужные сервисы карты. Проверьте лимиты и условия ключа. После изменения переменной Vercel выполните Redeploy.
7. Проверьте страницу в чистом браузере: интерфейс без входа, выбор карты, 3D-посадки, история, документы. Для ссылки жюри убедитесь, что настройки доступа Vercel не требуют входа в ваш аккаунт.

Руководство платформы: [Vite on Vercel](https://vercel.com/docs/frameworks/frontend/vite).

## Сделать ссылку заметной

После проверки реального адреса:

- В самом начале `README.md` замените сообщение «Онлайн-демо: ссылка появится…» на `**[Открыть TalAI →](https://ваш-проверенный-домен)**`.
- GitHub → **About → шестерёнка → Website**: тот же адрес.
- Description: `Учёт деревьев, 3D-планирование посадок и история обследований · React, TypeScript, 2GIS`.
- Topics: `trees`, `gis`, `urban-planning`, `react`, `typescript`, `2gis`, `kazakhstan`.

Не добавляйте непроверенный домен: занятый адрес может вести на чужой сайт.

## Перед передачей жюри

- `npm test`, `npm run build:demo`, `node scripts/demo-check.mjs`.
- Реальный домен разрешён для ключа 2ГИС; логотип и атрибуция карты видны.
- При отказе SDK не загружается; реестр доступен.
- Демо не делает запросов `/api/session`, `/api/project` или `/api/upload`.
- Юридические документы остаются проектами для проверки. Эта публикация демонстрации не означает готовность сервиса к приёму персональных материалов пользователей.
